# روضة الدروس

برنامج تعليمي متكامل لأطفال الروضة (٤–٦ سنوات): كتب تفاعلية، شرح وعروض وألعاب واختبارات، سبورة وأدوات الصف، ومصحف بتلاوات المشايخ المتزامنة مع الآيات.

- يعمل مباشرة من المتصفح، دون تسجيل دخول.
- نص القرآن الكريم بالرسم العثماني من [مشروع تنزيل](https://tanzil.net) (CC BY 3.0).
- التلاوات (الحصري المعلم، المنشاوي، العفاسي — الفاتحة والأجزاء ٢٨–٣٠) مأخوذة من ملفات everyayah.com، للاستخدام التعليمي غير التجاري.

## التشغيل من فلاشة
1. نزّل المستودع: زر **Code** ← **Download ZIP**، ثم فك الضغط على الفلاشة.
2. افتح الملف **«افتح روضة الدروس.html»**:
   - مع الإنترنت: يفتح أحدث نسخة من البرنامج تلقائيًا.
   - بدون إنترنت: يفتح النسخة المحفوظة على الفلاشة.
